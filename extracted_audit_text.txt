The inspected `/api/ai-router/route.ts` does not call Gemini or Groq; it normalizes query text, removes stop words, chooses a likely administrative level and asks the public NISR GIS endpoint for matching places. The repository manifest includes `@google/genai` and `groq-sdk`, but installed dependencies do not demonstrate model integration; the current route is the decisive evidence. The previous Gemini audit's statement that a live Gemini 3.8 Flash engine answers Kinyarwanda leader questions and creates leader cards is unsupported by the code that was inspected. At best this is a place-name search/assistant; it is not a general question-answering engine and it should not invent leaders or official facts. The source fallback calculates intersection between an accuracy circle and returned village polygons and explicitly reports a gap rather than fabricating a village. This is a sensible conservative design pattern, but the entire workflow needs real device tests; no direct live Android GPS test was performed as part of this audit. 7.2 Offline gaps The tracked file `public/offline/gasabo-boundaries.geojson` contains `features: []` and its own note says it intentionally contains no made-up polygons and that the full national GeoJSON must be generated.
